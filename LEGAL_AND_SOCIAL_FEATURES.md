## PART 2: REFERRAL PROGRAM

### $20 Referral Bonus Program

The Self Made Legends Referral Program allows users to earn money by inviting friends.

#### Program Overview

**What You Earn**: $20 per successful referral
**Total Earnings**: No cap - unlimited referrals
**Bonus Payment**: Credited within 24 hours

#### How It Works

1. **Generate Your Referral Link**
   ```
   GET /api/referrals/my-link
   ```
   Returns your unique referral code and shareable link

2. **Share Your Link**
   - Send link to friends: `https://selfmadelegends.app/join/ABC123XYZ`
   - Share referral code: `ABC123XYZ`
   - Share short URL: `sml.link/ABC123XYZ`

3. **Friend Signs Up**
   - Friend visits your referral link
   - Friend creates account with your code
   - You both receive $20 bonus when friend deposits

4. **Friend Deposits Money**
   - Friend deposits minimum $1 (any amount)
   - Referral automatically completes
   - $20 bonus credited to your account within 24 hours

#### Referral Requirements

**Valid Referrals**:
- ✅ Real person (verified identity)
- ✅ First-time user (new email)
- ✅ Completes account verification
- ✅ Makes first deposit (any amount)

**Invalid Referrals**:
- ❌ Duplicate emails or accounts
- ❌ Bot-generated signups
- ❌ Fraudulent accounts
- ❌ Self-referrals (can't refer yourself)
- ❌ Accounts that violate TOS

#### Referral Leaderboard

## PART 3: SOCIAL FEATURES

### Friends System

Add friends and connect with other traders on Self Made Legends.

#### Adding Friends

**Method 1: Direct Email**
```
POST /api/social/friends/add
Body: { "friendEmail": "friend@example.com" }
```

**Method 2: Referral Link**
- Send referral link to friend
- Friend signs up using your link
- Automatic friend connection

#### Friends List

View all your friends and their public stats:
```
GET /api/social/friends
Returns: {
  "friends": [
    {
      "userId": "user123",
      "email": "friend@example.com",
      "fullName": "Friend Name",
      "joinDate": "2026-01-15",
      "followers": 42
    }
  ],
  "totalFriends": 15
}
```

#### Friend Profile Visibility

**Public Information** (viewable by friends):
- Full name
- Join date
- Number of followers
- Number of following
- Total trades executed
- Win rate percentage
- Personal bio (optional)

**Private Information** (not shared):
- Password and authentication
- Account balances
- Personal financial data
- Bank account details
- Payment methods
- Transaction history
- Full trade details (only your own)

#### Removing Friends

```
POST /api/social/friends/remove
Body: { "friendId": "user123" }
```

#### Searching for Friends

```
GET /api/social/search?q=john
Returns: {
  "results": [
    {
      "userId": "user123",
      "email": "john@example.com",
      "fullName": "John Trader",
      "followers": 15
    }
  ]
}
```
