# Footwear tech pack template — Self-Made Legends

Footwear is not apparel with a different outline. It is built on a **last** —
a carved foot form — and almost every question below traces back to it. The
apparel template does not cover any of this, which is why this file exists.

A footwear factory will build exactly what is written. Where nothing is
written, they will choose, and they will choose what is cheapest to tool.

## 2. The last

**Nothing else can be specified until this is settled.** The last determines
fit, volume, toe spring, heel pitch and the shape of every pattern piece.

| | |
|---|---|
| Last number | Factory's own, once appointed |
| Toe shape | Round / almond / square |
| Toe spring | mm |
| Heel pitch | mm |
| Girth (ball) | mm at sample size |
| Width | Standard D, or state |
| Fit intent | True to size / half size down |

> **You almost certainly do not own a last.** A factory lends you one of theirs
> at no cost, and that is the right way to start. A bespoke last is $1,500–4,000
> and is a second-season decision, not a first-season one.

| | |
|---|---|
| Method | Cupsole / vulcanised / cemented / strobel |
| Lasting | Board / strobel / slip |

This single choice moves cost more than any other. Vulcanised is cheapest and
reads casual. Cupsole is dearer, stiffer, and reads premium. Say which and why.

## 5. Sole unit

| | |
|---|---|
| Outsole material | Rubber / gum rubber / EVA / TPU |
| Outsole compound | Durometer (Shore A) |
| Tread pattern | Describe it, or supply artwork |
| Midsole | EVA / phylon / PU, density |
| Heel stack height | mm |
| Forefoot stack height | mm |
| Drop | mm (heel minus forefoot) |
| Sidewall / foxing | Height, wrap, colour |
| Insole | Material, thickness, branding |

> **Tooling is the big cheque.** A bespoke outsole mould is $3,000–8,000 per
> size run, before a single pair is made. **Use a factory's existing sole unit
> for a first season.** Almost every factory has a library, and a stock sole in
> your colour with your foxing stripe is indistinguishable to a customer.

## 6. Branding

For each mark: exact placement measured from a fixed landmark, dimensions,
method, colour.

| Mark | Placement | Landmark reference | Size mm | Method | Colour |
|---|---|---|---|---|---|
| Script logo | Lateral quarter | From the heel seam and topline | | Embroidery / 3D print / debossed | |
| Crown | Heel or tongue | | | | |
| `SELF-MADE LEGENDS` / `EST. MMXXVI` | Medial quarter | | | | |
| Star | Midsole, medial | | | | |
| Tongue label | | | | Woven | |
| Insole print | | | | | |
| Outsole marking | | | | Moulded | |

**Embroidery on leather is not embroidery on fleece.** The needle perforates
the hide and it does not heal. Small text below roughly 4mm will tear or
distort. For fine work on leather, use a **debossed and foiled** mark or a
moulded 3D applique rather than thread — and say which.

## 8. Quality standard

- Bond strength: sole to upper, minimum 3.0 kg/cm peel
- Flex test: 30,000 cycles, no cracking or separation
- Colour fastness to rubbing, dry and wet
- No adhesive visible at the foxing line
- Left and right within 2mm on every measured point
- Eyelet pull-out strength
- Insole does not shift in wear
