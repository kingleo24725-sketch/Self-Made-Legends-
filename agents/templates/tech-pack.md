# Tech pack template — Self-Made Legends

The house standard. The Tech-Pack agent produces this structure as JSON; this
file is the human-readable form, and the reference for what "complete" means.

A factory builds what is written, not what was meant. Every blank below is a
decision someone will make for you — usually the cheapest one — if you leave it
blank.

## 3. Measurements

**Grade rule:** _state it, e.g. 2cm chest and 1cm length per size step_

Every row needs a tolerance. Without one the factory cannot tell whether they
passed, so they will decide for themselves.

| Point of measure | How to measure | Tol. | S | M | L | XL | 2XL |

| Chest, 2.5cm below armhole | Laid flat, across, doubled | ±1.0 | | | | | |
| Body length from HPS | High point of shoulder to hem | ±1.5 | | | | | |
| Shoulder to shoulder | | ±1.0 | | | | | |
| Sleeve length from CB | | ±1.0 | | | | | |
| Cuff rib height | Finished, folded | ±0.5 | | | | | |
| Hem rib height | Finished, folded | ±0.5 | | | | | |

Measure from fixed landmarks: **HPS**, centre front, centre back, side seam.
"From the top" is not a landmark.

> **Digitising approval.** A digitised DST file must be approved in writing by
> the house before bulk. Factories will otherwise digitise it themselves, and
> the first you hear of it is 300 finished units with a blobbed crest.

**Gold is embroidered, never printed.** Print cannot make metallic — it makes
flat mustard, and it looks cheap next to real thread.

---

## 7. Quality standard

- AQL 2.5 major / 4.0 minor on final random inspection
- No thread ends over 3mm
- Embroidery must not distort the ground fabric
- Colour continuity across panels within one garment
- No shading between cartons
- Measurements within stated tolerance on a 5-piece sample per size
